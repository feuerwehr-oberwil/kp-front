# Glossary – German domain terms

German is the **canonical domain language** of KP Front (see [CLAUDE.md](../CLAUDE.md)): UI
copy, identifiers, and docs use the Swiss fire-service terms on purpose, because the
operators think in them. This glossary exists so non-German contributors can *read* the
code and copy – it is **not** a license to rename anything to English.

| Begriff | English | What it is in this app |
| --- | --- | --- |
| **Lage** | situation | The live situation map – the app's main surface, rendered by `src/components/MapView.tsx`. In code and doctrine it is the Lage (`mode 'map'`, `areaLage`); the tab says «Karte» (`appConfig.copy.modes.map`) and the printed snapshot is the «Kroki» – user-facing copy no longer says «Lage» ([`copy-and-wording.md`](copy-and-wording.md)). |
| **Plan** | plan (whiteboard) | The plan whiteboard tab: drawing on Objektplan pages / blank boards with per-plan undo (`useBoardDoc`). Kept in feature parity with Lage. |
| **Einsatz** | incident, operation | One deployment/callout – the unit everything hangs off (incident + workspace blob, `src/lib/incidents.ts`). «Alle Einsätze» = the incident list. |
| **Verlauf** | log, operational journal | The append-only journal of the incident: human entries plus selected system events. Translated as "Log" in `src/config/copy/en.ts`. Never mutated – corrections are new appended events. |
| **Journal** | (same) journal | Code-side name for the Verlauf rows and their UI (`appConfig.copy.journal.*`, journal rows on `TimelineEvent`); «Einsatzjournal» is its printed form in the rapport. Verlauf (UI label) and Journal (code) are the same thing. |
| **Art** / **Bereich** | kind / area | A Verlauf row's one classification, two words (`lib/journalFilter`). **Art** is what a person wrote: «Info» (the plain entry), «Auftrag», «Sofortmassnahme», «Pendenz» – composer, filter, detail sheet and the Rapport's journal column say the same word. **Bereich** is only where an app row came from (Karte/Kroki, a plan or the Tafel, Trupps, Anwesenheit …). «Manuell» is gone (sweep E.5, 23.10.2026). |
| **Atemschutz** | SCBA / breathing-apparatus | The SCBA monitoring surface – on screen it is «Trupps» (tab, title, the close question's «Zu den Trupps»), «Atemschutzüberwachung» only in print; never «Atemschutz-Tafel»: per-Trupp clocks keyed on time since last radio contact (per FKS doctrine), with amber/alarm thresholds in `src/lib/atemschutz.ts` · `contactSeverity` / `truppAlarm`; `src/lib/alarm.ts` only plays the tone and the notification. |
| **Trupp** | crew, team (2–3 firefighters) | An SCBA entry team being tracked; can be placed on the map as an `Entity` of kind `'team'`. Numbered `Trupp N` per incident (one counter shared with unlinked chips) but called by its Gruppenführer everywhere – the number is a badge and what the Verlauf/Rapport match against ([`trupp-naming.md`](trupp-naming.md)). |
| **Mittel** | resources / materials | The material-use surface (`MittelView`): quantities of consumed material for billing/restock and the rapport. Not a live resource tracker. |
| **Einsatzleiter (EL)** | incident commander | The overall commander on scene; the `el` incident role. It reads everything but writes only the record domains (Anwesenheit/Zeitplan, Mittel, Checklisten, Rapport + Beilagen, Einsatzdaten – `RECORD_WORKSPACE_KEYS`, `EL_META_FIELDS`); everything tactical stays locked – the FU operates the picture. Not the same as the «Führungsansicht» (`el_view_default`), an *editor* login's hands-off mode. See [`roles-and-access.md`](roles-and-access.md). |
| **Führungsunterstützung (FU)** | command support (unit) | The command-support element that runs the command post – the app's primary user; maps to the `editor` incident role. |
| **AdFU** | member of the FU | *Angehöriger der Führungsunterstützung* – the individual operator at the tablet. Doctrine: the AdFU works the app, the C-FU coordinates. |
| **Erfassungsblatt** | (paper) capture sheet | The paper form for recording an incident when the app isn't used; the digital capture flow (`/e/<token>` poster) and the printed rapport mirror its fields. |
| **Einsatzrapport** | incident report | The official post-incident report, composed server-side as a PDF (`backend/app/report`). It is a pre-filled *form*, not a data export – printing never blocks on missing data. |
| **Stichwort** | dispatch keyword | The alarm keyword/title classifying the incident (e.g. «BRAND GROSS»); drives the category the server derives (`backend/app/data/alarm_keywords.json`; keyword section of the capture form). |
| **Funkkanal** | radio channel | The incident's radio channel, a synced workspace setting shown in the top bar (`appConfig.copy.*.funkkanal`). |
| **Hydrant** | hydrant | Water-supply point; a per-station reference geodata layer (WGS84 GeoJSON loaded via `admin_geodata`, rendered through `referenceLayersFromConfig`). |
| **Leitungskataster** | utility-line cadastre | The municipal map of underground water/gas lines – another reference layer (`rowLeitung` in the Ebenen panel). Station data, never bundled. |
| **Einsatzobjekt** | incident object / building | The building or site the incident is at; the picked object (`pickedObjectId`) is synced so all devices see the same one, and it selects the Objektplan tiles. |
| **Objektplan / Modul** | building emergency plan / plan module | Pre-made emergency-plan PDFs for an object, organized in module tiles (M1 access, … «Modul 3 Objektplan», …) per `src/lib/deploymentConfig.ts` module catalogue; imported per station via `admin_objects`. |
| **FKS / Faltkarte** | Swiss fire-service tactical-symbol convention | *Feuerwehr Koordination Schweiz* publishes the Faltkarte (folding card) of tactical map signs; KP Front's own symbol pack (`tools/gen_symbols.py` → `public/tactical-symbols.json`) follows those conventions. |
| **Anwesenheit** | attendance | The attendance surface: who is on scene, with von–bis time chips; feeds the rapport's personnel section (WinFAP computes hours from von–bis). |
| **Zeitplan / Schichtenplanung** | schedule / shift planning | The second view of the Anwesenheit (`src/components/ZeitplanView.tsx`, shift maths in `src/lib/shifts.ts`): a who × when grid planning each person's shifts. Purely forward-looking – it plans *verfügbar* and *eingeteilt* and never writes attendance, which stays the Anwesenheit's job. Prints as the «Zeitplan» Führungsformular. |
| **Deckung** | coverage | Only the Zeitplan's coverage – never the plan-on-map overlay (that is «Überlagerung»). The strip under the Zeitplan grid: three step lines counting available / planned / actually present per half-hour slot (`coverage()` in `src/lib/shifts.ts`), so a staffing gap is visible as a shape before it arrives. |
| **Führungsformular** | command form | The paper forms Swiss fire-service command staff work from. KP Front renders its own («Zeitplan», the rapport) server-side for printing rather than asking anyone to fill them in by hand. |
| **Ebenen** | (map) layers | The layers panel (`appConfig.copy.panels.layers`) toggling reference layers, vehicles, and the base map; a pinned dock on the Lage surface. |
| **Tafel** | (blank) board | Only the Plan's template pages (blank boards). Not the Atemschutz surface – that is «Trupps». |
| **Verknüpfung** | (map) link | A plan sheet tied to the map by point pairs (`whiteboard.georef.*`, code: georef). Its quality is «Genauigkeit», its scale chip «Massstab auto», copying it to a sibling Modul «Kopieren». «Referenz», «Passung», «Deckung» are retired for it. |
| **gespeichert / synchronisiert** | saved / synced | «gespeichert» = safe on THIS device; «synchronisiert» = reached the other devices (the head pill's green state), noun «Synchronisierung» (owner, 13.11.2026 – round 2's «übertragen» is retired again). «Netz» is the network. A bare «Sync» and «lokal gespeichert» are retired from operator copy; «Server» stands only in «Server nicht erreichbar». |
| **herunterladen** / **sichern** | download / secure (Auftrag) | A file leaving the app is «herunterladen» («Einträge herunterladen»); «sichern» is only the Trupp Auftrag. |
| **Abgleich** | (personnel) match | Importing the roster from an external provider («Personal mit {provider} abgleichen»), not «synchronisieren». |
| **Sprachnotiz** / **Audiodatei** | voice note / audio file | A recording made in the app / an imported recording. «Audionotiz», «Externe Audioaufnahme» are retired; stored Verlauf rows keep their words. |
| **Basiskarte** | base map | The map background (Carto / OSM / satellite), switched at the top of the Ebenen panel. |
| **LV95 / WGS84** | Swiss vs. global coordinates | LV95 is the Swiss national grid (7-digit metres); the map renders WGS84 `[lng, lat]` everywhere, converting only at the edges via `src/lib/geo.ts` (`wgs84ToLV95` / `lv95ToWgs84` / `fmtLV95`). |
| **Station** | fire station (a.k.a. Wache) | One deployment = one station (single-tenant): per-station config, branding, geodata and integrations all hang off it (see `docs/CONFIGURATION.md`). |
